STAYING CURRENT

Update Guide

One command in Claude updates the extension. Then reinstall the Claude connector so the two match.

Chrome never updates a Load unpacked extension for you, so every update is two quick jobs: run one command in Claude, then reinstall the Claude connector. To find out you are behind, open Settings in the extension and click the refresh icon next to Version - when it says "Update available", come back here.

1 Run the update command in Claude

Every time. Claude runs the update script for you - no downloading, unzipping or dragging files around.

  1. Click Copy update prompt for Claude below
  2. Paste it into Claude Code and press Enter. If Claude does not know where the extension lives, give it the path to the NiCE Designer Chrome folder you loaded originally
  3. Claude runs self-update.sh from inside that folder. It compares your installed version with the published one, downloads the new build, and copies it over your folder in place
  4. Paste chrome://extensions into your browser's address bar and click Reload on NiCE Designer Suite. This last click is always yours - Chrome does not let a script do it
2 Reinstall the Claude connector

Every time, so the connector matches your extension. The new connector file is inside the folder Claude just updated.

  1. In Claude Desktop, open Settings > Extensions, click the ... (three dots) next to nice-designer-mcp, and choose Uninstall
  2. Open the NiCE Designer Chrome folder and double-click "Click to install Claude Connector.mcpb", then confirm the two prompts
  3. Force quit Claude Desktop and reopen it - see the warning below
  4. Still missing a tool or skill? Use the "Not seeing a new tool or skill?" link in the extension's Supercharge panel - it points you back at the .mcpb file
