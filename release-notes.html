Release Notes

What's shipped in each version of NiCE Designer - features, improvements, and fixes.

v10 LATEST
June 2026
New features
  • Complete redesign: new icons, UX, and micro-animations throughout the interface
  • Role-based onboarding: first-launch modal asks for your role; adjusts default panel, skill set, and suggested MCP tools. Re-selectable in settings.
  • Claude / MCP skills (9): apply_token_fix, apply_all_fixes, get_audit_results, get_selected_node, set_selected_node, export_css, get_history, undo_fix, convert_design_system. Callable from Claude chat or any MCP-compatible client.
  • Edit mode: click the pencil in the header to edit webpages with familiar design tools
  • Edit history (undo/redo): full history stack in Chrome extension; each fix is logged, undo/redo per step
  • Export fixes as CSS: Export CSS button outputs all applied fixes with rule count and token names
Improvements
  • Semantic color matching: context-aware token lookup considers role (text, background, border, icon)
  • SOL to Lyra conversion: token mapping is context-aware, correctly handles tokens that differ by semantic role
  • Serialized MCP messages: calls queued and processed in order, preventing race conditions
  • Auto-snooze after Apply All: fixed items automatically snoozed; toggleable in settings
Fixes
  • Custom hex values no longer revert on blur
  • Variable binding preserved when applying fix to a node with existing bound variable
  • Chrome extension detection no longer fails on pages that load in an iframe
v9
May 2026
New features
  • Vision/screenshot support for Claude: Claude can pull in a visual to make targeted changes
  • Per-row revert: Apply/Replace leaves a revert link on each row; one click restores prior state including variable bindings
  • Custom value live edit: hex input for colors, px input for font size, spacing, and radius on every row
  • Export applied fixes: returns a CSS document of every live edit in the session, including rule count
  • Per-category audit totals: every audit tile shows bad/total (e.g. 15/147 Colors); design score divides by per-category sum
  • Family-aware text matching: font family + size + weight all considered when flagging wrong-system text
  • 10x faster library load: variable imports parallelized 16-wide with 10-second timeout fallback
Fixes
  • Radius variable binding now correctly binds all four corner properties
  • Open Sans SemiBold loads reliably across weight-naming variants
  • Audit ring stability fixed - no more race condition on pull refresh
  • MCP server v0.5.0 with four new revert_single_* tools and custom value fields on apply tools
v8
April 2026
New features
  • MCP connection with Claude: NiCE Designer now includes an MCP server; Figma and Chrome share context for complex AI-driven tasks
  • Standalone popup mode for Chrome: dock the extension on a second monitor via a toggle in settings
  • Chrome extension no longer needs to reset per window when switching pages
