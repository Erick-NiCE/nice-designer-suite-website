Frontend Audit
Is this compliant and accessible?

Why use it: You need one defensible number for whether a page or frame is compliant and accessible - plus the ranked list of exactly what's dragging it down - instead of running separate design and a11y checks and reconciling them yourself.

What it handles
  • One score for design-system compliance and accessibility, merged into a single pass
  • Filter by Design System, Accessibility, or Accessibility (Full)
  • Colorblind simulation & small tap-target overlay (Chrome)
  • Live component checks via Storybook integration
  • Cross-client parity check — diff a Figma artboard against the live page (via Supercharge)
  • Severity-ranked report you can fix from, right in the panel

Frontend Editor
Design directly in the browser

Why use it: You want to try a style change on a real, live page - not a code branch, not a static mockup - and see it hold up immediately, with a full undo if it doesn't.

What it handles
  • Familiar layer panel for any live page
  • Real-time style overrides without touching code
  • Magic effects — dark mode, hover glow, liquid/plasma & more, one click
  • Full edit history with undo & redo

Spec Mode
Give me the code

Why use it: Engineering asked for the exact CSS on a component, and you don't want to hand-measure a Figma frame or reverse-engineer computed styles off a live element yourself.

What it handles
  • Select and inspect any element, in Figma or on a live page
  • Production CSS with Lyra tokens substituted automatically

Supercharge
Some features need a little more

The Figma plugin and Chrome extension work great on their own. But certain features unlock only when you connect to Claude via the local MCP server. We call this Supercharge - Claude acting as the brain while the plugin and extension act as the hands.

🔗
What is Supercharge?
Supercharge is the connection between Claude and NiCE Designer's tools. Start the local MCP server, connect Claude Desktop, and Claude can drive both Figma and Chrome simultaneously using natural language - running multi-step workflows that neither tool could do alone.
🎯
What requires Supercharge?
Any workflow that spans both clients: Figma-to-Chrome parity checks (via Audit), pushing an artboard's styles to a live page, SOL → Lyra conversion work done directly with Claude, and all 11 Claude skills. Single-client audit features work standalone.
🚀
Getting started
Install the MCP server from the download package, run node src/index.js in the packages/mcp-server/ folder, and connect Claude Desktop. See the Install Guide for the full setup walkthrough.
