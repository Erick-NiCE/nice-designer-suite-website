# Settings page

Use for: configuration with many small independent choices.

Inside the shell panel: title, a left in-page list or Tabs (real) for sections, each section a Card with a heading, a one-line description, and its controls (Switch for on and off, Select or Text Input for values). Each section saves on its own (a Save button in the card) or immediately with a Toastr confirmation, never a mix. Dangerous settings sit in their own section with a critical Button behind a Modal confirmation.

States: loading, saved, failed to save, no permission to change.
Acceptance extras: labels describe the effect, not the field name; the default value is stated.
