GETTING STARTED

Install Guide

Start with the Chrome extension, then connect Claude Desktop to supercharge it. The Figma plugin is a separate install at the bottom - grab it whenever you need it.

1

Install the Chrome Extension

Prerequisites

Chrome or Edge (Chromium-based) with Developer Mode enabled in chrome://extensions.

How to install
  1. Download the latest release: NiCE-Designer-V11.1.zip Coming soon!
  2. Unzip the downloaded package to a location you'll keep it
  3. Go to chrome://extensions (or edge://extensions) and enable Developer Mode
  4. Click "Load unpacked" and select the NiCE Designer Chrome folder from the unzipped package
  5. The NiCE Designer icon appears in your Chrome toolbar
📍

Where is Developer Mode? Top-right in Chrome, bottom of the left sidebar in Edge - and Load unpacked only appears once it's on. Both are marked up below.

How to use it

Navigate to any web page and click the NiCE Designer icon in the toolbar. The inspection panel opens alongside the page. For a dedicated second-monitor view, click the pop-out icon in the extension settings panel.

ℹ️

The extension persists per window. No reset is needed when switching tabs or navigating to a different page.

💡

First launch: a Welcome screen offers Simple (Lite mode - just Frontend Audit and Design System) or the Full toolkit, followed by a short guided tour. Switch modes or replay the tour anytime from Settings.

2

Install Node.js

What it does

Claude Desktop needs Node.js on your machine to run the local MCP server that connects Claude to the Figma plugin and Chrome extension. The Figma plugin and Chrome extension still work fully as standalone tools without it - this step only unlocks Supercharge.

Option A - Download the installer (recommended, no terminal)

Go to nodejs.org, download the installer for your OS (the big green button - it's the LTS version), and double-click it like any other app installer. That's it - no terminal, no typing commands.

Option B - Install via npm/a package manager (for developers)

If you're comfortable with a terminal and already use a package manager, that works too:

# macOS (Homebrew) brew install node # Windows (winget) winget install OpenJS.NodeJS.LTS

Either option gives you the same thing: a working node command that Claude Desktop can call. You only need to do this once per machine.

ℹ️

You do not need to run npm install or start the server yourself - the downloaded package already includes its dependencies, and Claude Desktop starts the server automatically in the next step.

3

Connect Claude Desktop Supercharge

One-click install (recommended)

The NiCE Designer Chrome folder - the same one you loaded in step 1 - has "Click to install Claude Connector.mcpb" sitting directly inside it. Double-click it, confirm the two prompts, and "nice-designer-mcp" appears as an installed extension - already running. No file paths, no JSON, no terminal.

🔄

Updating the connector: there's no in-place upgrade. When a new version ships, uninstall the existing connector from Settings > Extensions first, then double-click the new .mcpb file to install it.

Turn on Supercharge

Last step, and the one that actually switches everything on. Open the NiCE Designer extension, go to the Supercharge panel, and flip the toggle to On. The header should show a green dot and Live at ws://127.0.0.1:7331 - that's your confirmation the extension and Claude are talking to each other.

If a tool or skill you expect is missing after an update, use the "Not seeing a new tool or skill?" link in that same panel - it points you back at the .mcpb file to reinstall the connector.

Manual config (advanced / no .mcpb support / running from source)

If you're on a Claude Desktop version that doesn't support .mcpb connector files yet, add the server entry to claude_desktop_config.json by hand instead - Claude Desktop will still start the server itself, same as the one-click path:

// claude_desktop_config.json { "mcpServers": { "nice-designer": { "command": "node", "args": ["/path/to/nice-designer/packages/mcp-server/src/index.js"] } } }

Use an absolute path to the index.js file. Relative paths will not work. Restart Claude Desktop after saving.

Running it yourself in a terminal (developers / non-Claude-Desktop MCP clients)

Neither option above is needed if you just want to run the server standalone - for example to connect a different MCP client, or if you're working from a git clone instead of the downloaded package:

# only needed from a fresh git clone - the downloaded package # already includes node_modules cd packages/mcp-server npm install node src/index.js

The server starts on ws://127.0.0.1:7331. Set NICE_MCP_WS_PORT before starting to use a different port:

NICE_MCP_WS_PORT=8080 node src/index.js
Best practice

Load a skill before using MCP tools for the best results. For example, tell Claude: "Load the lyra-visual-patterns skill" before starting a Lyra conversion workflow.

4

Verify Everything Is Working

Quick checks
Open the Chrome extension on a web page - the toolbar should appear with inspection controls
In the extension's Supercharge panel, the toggle is On and the header reads Live at ws://127.0.0.1:7331 with a green dot - Claude Desktop starts the server itself, so there's nothing to run manually
Ask Claude: "Call list_targets" - it should respond listing which clients are currently connected (Figma, Chrome, or both)
In Chrome, click the refresh icon next to the version number in Settings to confirm the update checker reaches the latest release - see Release Notes for what's new.
Open the Figma plugin on a frame - if you installed it, the audit panel should appear with color, type, and spacing scores
5

Install the Figma Plugin Separate install

How to install

Independent of everything above - the plugin installs straight from the Figma Community and needs none of the steps 1-4. Do it whenever you want to audit designs on the Figma canvas as well as in the browser.

Open Figma, right-click the canvas (or open the main menu) and go to Plugins. Search for "NiCE Designer" and click Install.

Or open the plugin directly on the Figma Community page:

figma.com/community/plugin/1623361730572479462

How to use it

With a frame or layer selected, right-click and go to Plugins > NiCE Designer. Alternatively, open the Resources panel in Figma (Shift+I), switch to the Plugins tab, and search for NiCE Designer.

Notes

The plugin runs entirely inside Figma. No backend or server is required for standalone audit and convert workflows. Connect to the MCP server to enable Claude integration and cross-client features.

Troubleshooting

Common Issues

🌐 Chrome extension not loading
Verify that Developer Mode is enabled in chrome://extensions (top-right in Chrome, bottom of the left sidebar in Edge). If the extension still won't load, try removing it and re-loading the unpacked folder. Make sure you're selecting the NiCE Designer Chrome folder itself - the one containing manifest.json - not the folder above it.
🔌 MCP server not connecting
Check that port 7331 is not already in use by another process. Use NICE_MCP_WS_PORT=7332 node src/index.js to run on a different port. Make sure the path in claude_desktop_config.json is an absolute path, not relative.
🤖 Claude can't see any targets
At least one client - the Chrome extension or the Figma plugin - must be open and connected to the MCP server. Call list_targets first - it will tell you exactly which clients are currently registered. If the list is empty, check the connections in each client.
🎨 Plugin won't open
Make sure you installed from the Figma Community (not a local unpacked version). Check that the plugin isn't in your organization's blocked plugin list - contact your Figma admin if unsure.
