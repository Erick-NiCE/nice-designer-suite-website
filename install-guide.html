GETTING STARTED

Install Guide

Start with the Chrome extension, then connect Claude Desktop to supercharge it. The Figma plugin is a separate install at the bottom - grab it whenever you need it.

Staying current

Updating the App

The Chrome extension is a Load unpacked install, so Chrome never updates it for you - that is a browser restriction on sideloaded extensions, not a setting we can switch on. Settings > Version has a refresh button that tells you when a newer build is out; below are the three ways to actually take it. The Figma plugin is different - it updates through Figma itself, so there is nothing to do there.

1 Download from the website

Best for your first install, or updating by hand while keeping your settings, Supercharge connection, welcome-tour state, and anything else stored in the extension.

  1. Download the latest release: NiCE-Designer-V11.3.zip Coming soon!
  2. Unzip it - this gives you a new NiCE Designer Chrome folder
  3. Drag the files out of that new folder and into your existing, already-installed folder - the same one you originally pointed Load unpacked at - overwriting everything when your file manager asks
  4. Go to chrome://extensions and click Reload on NiCE Designer Suite
2 Check for updates in Settings

Best for finding out you are behind, then updating on your own terms.

  1. Open the side panel and go to Settings
  2. Click the refresh icon next to Version. It reads the published version and tells you either "You're up to date" or "Update available"
  3. Click the download link it gives you - it grabs the zip and brings you straight to the manual walkthrough above, so you land on the same "same folder, drag files in" steps instead of having to find them yourself
3 Ask Claude to do it

Best for the fastest route, if you already use Claude Code on this machine.

  1. In Claude Code, ask it to update NiCE Designer and point it at your installed extension folder
  2. Claude runs self-update.sh from inside that folder. The script compares your installed version against the published one, downloads the new build, and copies it over your folder in place - no unzipping, no dragging files around
  3. Go to chrome://extensions and click Reload. This last click is always yours - Chrome does not let a script do it
Troubleshooting

Common Issues

Reading a Figma design that is open in Claude Design

Claude Design renders a real page, unlike figma.com, whose canvas is one WebGL element with no readable markup. That means the Chrome extension works there normally: click Pick, select any element, and Spec Mode reads it, with the same data available to Claude through the MCP tools. This is the shortest route from a Figma design to code, and it is available on a view-only Figma seat.

Chrome extension not loading
Verify that Developer Mode is enabled in chrome://extensions (top-right in Chrome, bottom of the left sidebar in Edge). If the extension still won't load, try removing it and re-loading the unpacked folder. Make sure you're selecting the NiCE Designer Chrome folder itself - the one containing manifest.json - not the folder above it.
MCP server not connecting
Check that port 7331 is not already in use by another process. Use NICE_MCP_WS_PORT=7332 node src/index.js to run on a different port. Make sure the path in claude_desktop_config.json is an absolute path, not relative.
Claude can't see any targets
At least one client - the Chrome extension or the Figma plugin - must be open and connected to the MCP server. Call list_targets first - it will tell you exactly which clients are currently registered. If the list is empty, check the connections in each client.
Plugin won't open
Make sure you installed from the Figma Community (not a local unpacked version). Check that the plugin isn't in your organization's blocked plugin list - contact your Figma admin if unsure.
