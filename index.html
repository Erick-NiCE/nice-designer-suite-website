NiCE Designer

A Figma plugin and Chrome extension that audits design system compliance, applies token fixes, and connects to Claude via MCP for AI-assisted design work. Built for SOL and Lyra.

Download v10
v10 · June 2026
What can it do

Built around what you need to get done

Whatever seat you're in, NiCE Designer takes a specific job off your plate.

📊

Product Manager

Get a live compliance score across 144 CXone pages, so drift from SOL or Lyra shows up before it ships instead of during a review.

🎨

Designer

See every off-system color, spacing, and type choice on your Figma frame instantly, then fix it in one click instead of hunting down the right token by hand.

🤖

Developer

Ask Claude to audit, convert, or export CSS for a page in plain language - it drives the Figma plugin and Chrome extension for you over MCP.
